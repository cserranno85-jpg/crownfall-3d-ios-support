Support for the Crownfall realm

This page provides official support information for the iOS version of Crownfall 3D: Arcane Chess.

Need direct help? Email support@caivratech.com with your device model, app version, platform, and a short description of what happened.

What to include in a support request

  • Platform: iOS
  • Device model and operating system version
  • App version/build number, if visible
  • What screen you were on
  • Steps that caused the issue
  • Screenshot or screen recording, if it helps explain the problem

Quick Troubleshooting

  • Game will not launch: fully close the app, reopen it, restart the device, and confirm you are running the latest version available on Apple App Store.
  • Board or pieces look misaligned: rotate the device once, return to your preferred orientation, then reopen the match. Include a screenshot in your support email if the issue remains.
  • Touch input feels inaccurate: remove screen overlays or accessibility zoom settings temporarily, then test again. Report the exact device model if the issue continues.
  • Performance feels slow: close other apps, disable battery saver if possible, restart the device, and update the app when a new build is available.
  • Progress/settings appear missing: check whether the app was deleted, reinstalled, or device storage was cleared. Local-only data may be removed when app data is cleared.

Game Basics

Crownfall 3D: Arcane Chess is a fantasy strategy board game inspired by chess but designed around its own Crownfall rules, pieces, and board identity.

  • Plan your movement carefully across the Crownfall board.
  • Use each piece’s special movement style to control lanes, pressure enemy formations, and protect your Crown.
  • Win conditions and move validation should be handled by the game itself; illegal moves should not be accepted by the app.

Fair Play and Stability

For the best experience, use the current official version from Apple App Store. Avoid modified builds, unofficial APKs, altered device settings, or third-party overlays that may interfere with touch input, rendering, or save behavior.

Updates

Caivra Tech LLC may release updates to improve board presentation, piece visuals, rule clarity, performance, accessibility, and device compatibility. Keep automatic updates enabled to receive the newest supported version.

Accessibility

If visual contrast, readable labels, motion, or touch-target sizing causes difficulty, contact support with your device type and a description of the issue. Accessibility feedback helps prioritize future improvements.

Privacy and Data
